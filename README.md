# HTT 工具箱（HTT Toolbox）

花提提制作的 Blender 渲染测试与动画阴影检查工具箱。

- 当前版本：`1.7.10`
- 支持版本：Blender `4.2 LTS`—`5.2.2 LTS`
- 作者：花提提
- 界面语言：中文

## 下载

[下载 HTT Toolbox v1.7.10](https://github.com/huatiti/blender-htt-toolbox/raw/refs/heads/main/htt_toolbox_v1.7.10.zip)

下载后不要解压，直接在 Blender 中选择该 ZIP 安装。

## 主要功能

- 指定帧输出单帧 PNG 渲染测试。
- 指定起止帧输出 PNG 序列或 H.264 MOV 渲染测试。
- 渲染结束后显示完成状态、帧范围和保存位置。
- 抽样检查最终相机画面，查找疑似阴影或暗部闪烁帧。
- 检查 Eevee Shadow Pool、阴影分辨率比例与可渲染灯光数量，提示容量风险。
- 无需写出图片即可推进时间轴，检查灯光投影、能量、可见性和变换跳变。
- 提供快速、标准、最终三档检查精度。
- 支持提升阴影池、降低阴影分辨率以及关闭次要灯光或体积阴影。
- 修改前自动保存快照，可一键恢复并重新检查。
- 提供修改墙面、修改灯光和灯光链接等亮斑处理方法。

阴影检查不会修改模型或写出图片，可按 `Esc` 在帧间取消；结束后会恢复原帧和分辨率设置。

## 安装方法

1. 下载 `htt_toolbox_v1.7.10.zip`，不要解压。
2. 打开 Blender。
3. 进入“编辑 → 偏好设置 → 插件”。
4. 选择“从磁盘安装”，打开下载的 ZIP。
5. 启用 **HTT 工具箱（HTT Toolbox）**。
6. 返回 3D 视图，按 `N` 打开侧栏，选择“htt工具箱”。

## 使用提示

- 首次启用时，两个功能子面板默认收起。
- “最终”检查档会采用项目完整渲染分辨率，耗时明显高于快速和标准档。
- 灯光链接在 Blender 4.5 以下仅支持 Cycles；插件会根据 Blender 版本和当前渲染器提示无效操作。
- 执行自动调整后，如效果不合适，可使用对应的恢复按钮还原。

## 更新方式

下载新版 ZIP 后，从 Blender 的插件安装界面重新安装即可。建议更新前保存当前工程。
